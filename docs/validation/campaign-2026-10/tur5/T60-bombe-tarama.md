# T60 — Bombe kalınlığı toplu tarama

Tohum 60 ile 150 yarım küre ve 150 torisferik vaka üretildi. Her API vakası `run_case` ile çalıştırıldı.

Bağımsız hesaplar UG-32(f) yarım küre ve UG-32(e) torisferik denklemlerini kullandı. Torisferik denetim t_req karşılaştırmasıyla sınırlıdır. Uyuşma ölçütü ±%1'dir.

API başarı bayrağı: 300/300. Ayrıntılar `results.json` dosyasındadır.

SONUÇ: vaka=300 · uyuşur=300 · uyuşmaz=0 · veri_yok=0 · kapsam_dışı=0
