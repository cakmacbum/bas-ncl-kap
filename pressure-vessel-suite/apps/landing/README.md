# Pressure Vessel Suite landing page

Plain static HTML, CSS and vanilla JavaScript. Serve this directory with any static host; there is no build step.

Before publishing, set `APP_URL` in `main.js` to the production application URL. Sign in and Start free links are rewritten from that value, with HTML fallback URLs for users without JavaScript.

The Vercel configuration provides clean URLs and security headers. The CSP permits the Google Fonts stylesheet and font files used by the page. All product descriptions are limited to the currently documented V1 scope; engineering results require qualified review.
