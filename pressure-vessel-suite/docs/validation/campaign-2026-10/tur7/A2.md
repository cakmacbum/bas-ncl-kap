## Yöntem (bağımsızlık)
- `oracle.py` yalnız girdi parametrelerinden hesaplayan saf fonksiyonlardır (UG-27(c)(1), UG-32(d), UG-37(c)). Hesap paketlerinin kaynağı okunmadı (temiz oda).
- `ref.csv` API çağrılmadan önce yazıldı (dosya zamanı: ref 23:55:20, api 23:55:30). `api.csv` ayrı yazıldı; `compare.py` en son birleştirdi.
- Hiçbir referans sütunu API'den türetilmedi. Eşik: bağıl hata <= %1.
- Girdi: taban tank `vertical_leg_tank`; D_i 300–2500 mm, P 0.2–6 MPa, S 100–200 MPa, E (0.7–1.0, 0.7/0.85/1.0 ağırlıklı), CA_i 0–3 mm. E, SHELL-01/HEAD-L'nin bağlı olduğu WJ-01 birleşimine yazıldı. Nozulda d = nozul iç çapı (0.05–0.4·D_i), boyun kalınlığı 4–24 mm.

## Birebir-aynı-string kontrolü (kırmızı bayrak, açıklaması)
300 satırın 221'inde ref_value ve api_value string'i birebir aynı: gövde 100/100, bombe 100/100, nozul 21/100 (E=1 vakaları; V1 sütunu bunlarda V2 ile aynı değer).
Neden: oracle, API ile aynı cebirsel formülü aynı işlem sırasıyla (P·R_c/(S·E−0.6P) gibi) IEEE-754 double ile hesapladığı için sonuç bit-bit çıkıyor; değer kopyası değil. Kanıtlar: (1) ref.csv API'den önce yazıldı; (2) nozul V1 sütunu 78 vakada API'den farklı, yani oracle API'yi izlemiyor; (3) 40 haneli Decimal ile yeniden hesaplanan bağımsız referansa göre API bağıl hata <= 5,5e-16 ve 200 vakada sıfırdan farklı (bit düzeyinde aynı olmama, aritmetiğin gerçekten ayrı hesaplandığını gösterir).
Sınırlama: bit-bit aynılık, iki tarafın aynı formülü kullandığını gösterir; formülün kendisini (ör. UG-27 katsayıları) doğrulamak için dış kaynak (kodun el hesabı/örnek problem) gerekir. Burada formüller kodun metninden bağımsız elle yazıldı.

- Nozulda t_r için E belirsizliği (yukarıda): API E=1 kullanıyor (V2). Karar için ASME UG-37(a) yorumu gerekir; E_host<1 ve nozul açıklığı kaynak dikişinden geçmiyorsa E=1 yaygın yorum, ama burada hüküm verilmedi.
- A1 ve A_total için bağımsız referans kurulmadı (API değerleri `api.csv`'de duruyor: `api_A1`, `api_A_total`); E1, tn düşümü ve CA varsayımı belirsiz olduğundan kapsam dışı bırakıldı.
- Nozul CA'sı (d'nin korozyon payı) belirsiz; yukarıdaki d=ID tanımı seçildi ve sonuçlar bu seçimle raporlandı.
- Tüm 300 vakada HTTP 200; hata/VERİ_YOK yok.
