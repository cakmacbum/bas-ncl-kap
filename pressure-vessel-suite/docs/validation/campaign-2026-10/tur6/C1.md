# C1 — T63 nozul, eliptik ve T45 torisferik

Komut: `python -m tools.campaign.tur6.t63_dongu.run` — 300 vaka tamamlandı.

| Bileşen | Vaka | UYUŞUR | UYUŞMUYOR | VERİ_YOK |
|---|---:|---:|---:|---:|
| A — Nozul UG-37(a) | 120 | 48 | 72 | 0 |
| B — Eliptik UG-32(d) | 120 | 120 | 0 | 0 |
| C — Torisferik UG-32(e), T45 | 60 | 60 | 0 | 0 |
| Toplam | 300 | 228 | 72 | 0 |

Nozul `required_area` bağımsız UG-37(a) hesabıyla ±%1 karşılaştırıldı; API `utilization_ratio` için PASS eşiği ≥1 uygulandı. 72 sapmanın 70'inde kullanım oranı 1'in altındaydı; kalan 2 vakada bağımsız `required_area` farkı %1'i aştı. Eliptik girdide `crown_depth` kullanılmadı; `D_c = D_i + 2·CA_i` ile t_required ±%1 doğrulandı. T45'te `L = D_o`, `r = 0.06L`, UG-32(e) referansı bağımsız hesaplandı.

Referanslar API çağrılarından önce `tools/campaign/tur6/t63_dongu/ref.csv` dosyasına yazıldı. Ayrıntılar aynı dizindeki `results.json` ve `kontrol.json` içindedir.
